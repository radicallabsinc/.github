# Radical Labs

Redefining experiences through radical technology for people to unlock their full potential.

## Projects

### 🪁 RadicalX

**[RadicalX](https://radical-labs.co/radicalx)** is an iOS app for the riding community, starting with kitesurfing.

A project built to help riders connect, discover spots, see who's out on the water, and coordinate sessions, rides, and trips.
